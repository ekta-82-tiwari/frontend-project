# Coffee Shop Website ☕

## About Project

This is a simple Coffee Shop Website created using HTML and CSS. The website provides information about coffee products, services, and contact details with a clean and responsive design.

## Features

* Responsive Design
* Home Page
* About Section
* Coffee Menu Section
* Contact Section
* Attractive User Interface

## Technologies Used

* HTML5
* CSS3

## Project Structure
coffee-shop/
├── index.html
├── style.css
├── images/
└── README.md

## How to Run

1. Download or clone the project.
2. Open `index.html` in your browser.
3. Explore the Coffee Shop Website.
